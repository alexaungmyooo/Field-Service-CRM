## Database authorization meaning

A future effective private authorization must contain a `databaseConnection` object with exact
schema version, protocol, host, port, database, user, runtime-credential SHA-256, and canonical URL
SHA-256. Its top-level package and run IDs must match the execution environment. The actual
credential and URL remain private runtime values and must not appear in evidence.

The child marker is not an authorization substitute. It is derived only after the parent validates
the effective record and covers package, run, URL, credential, and authorization binding. Both the
MJS and TypeScript authorization guards independently require exact package/run plus effective and
checkpoint-authorized state. Static agreement proves contract shape, not runtime propagation.
