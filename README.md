# Field Service CRM

Field Service CRM is a documentation-first project for a configurable, multi-organization field
service management and customer relationship platform.

The initial domain is Myanmar air-conditioning service operations. The target product must remain
capable of supporting small service businesses, multi-branch organizations, enterprise field
operations, and later adaptation to other service industries.

## Current status

- Phase: Product Discovery
- Requirements: Draft
- Architecture: Not started
- Application code: Not authorized
- Technology stack: Not selected

Start with [`docs/00_PROJECT_START_HERE.md`](docs/00_PROJECT_START_HERE.md).

## Working method

The project separates:

- public product and engineering truth under `docs/`;
- permanent agent instructions in `AGENTS.md`;
- private, local execution authorization and evidence under `internal-local/`;
- application implementation, which begins only after the applicable discovery and architecture
  gates are accepted.

The repository is not yet an executable application.
